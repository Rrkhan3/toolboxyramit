# ToolBoxy — Legitimate Backlink Strategy

Backlinks are **off-page SEO**. They are not fixed by website code.
Do not buy spam links, use link farms, PBNs, or automated directory spam.

## Current status
- Codebase does not and should not generate backlinks.
- Score impact from external SEO checkers is expected until organic links grow.

## Legitimate approaches (manual, relevant, editorial)

1. **GitHub**
   - Public TEST/production repos with a clear README
   - Link from personal/org GitHub profile and pinned projects

2. **Product & tool directories (only if accepted by editors)**
   - AlternativeTo, Product Hunt, BetaList, or similar — submit honestly
   - Dev tool lists that accept free utilities

3. **Technical content**
   - Short genuine articles (blog, Dev.to, Hashnode) about privacy-first browser tools
   - Natural mention of toolboxy.xyz when relevant — no keyword stuffing

4. **Communities**
   - Nepal tech communities, developer Discords/Forums — helpful answers, not spam
   - Stack Overflow / related sites only when answering real questions

5. **Social profiles**
   - Official profiles (X, LinkedIn, YouTube) linking to https://toolboxy.xyz/
   - Share useful tool demos; avoid repetitive automated posting

6. **Partners & friends**
   - Relevant sites that genuinely use or recommend the tools
   - Guest posts only where the host’s audience matches

## Do not
- Buy backlinks
- Use link networks or expired domain schemes
- Add hidden links or doorway pages in the ToolBoxy codebase
- Mass-submit to low-quality directories

## Measurement
Track referrals in Google Analytics **only after** the user has granted Analytics consent.
