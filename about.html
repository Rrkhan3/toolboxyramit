About ToolBoxy

ToolBoxy is a free online utility platform designed to make everyday digital tasks easier. Every tool has its own page with a clear interface, instructions and examples.

What you will find

  • Calculators for percentages, dates, loans, interest and health.
  • Text tools for counting, cleaning, sorting and converting text.
  • Developer tools for JSON, Base64, URLs, UUIDs, HTML and CSS.
  • Image tools for resizing, compressing, cropping and converting images.
  • Converters for length, weight, temperature, area, volume, speed, time and data storage.

How it works

ToolBoxy is a static website. The tools run in your browser using JavaScript, so your text and images are not sent to a server by the tools.

Our approach

Simple tools, fast results and no unnecessary complexity. We only list tools that actually work, and we plan to add more over time.
