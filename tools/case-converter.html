Case Converter

Transform text between common cases for code, titles and editing. Developers and writers switch formats without retyping. Conversion is local.

Everything runs in your browser. Your input is not sent to a server by this tool.

How to use the Case Converter

  1. Paste text.
  2. Choose a case button (UPPERCASE, Title Case, camelCase, etc.).
  3. Copy or download the result.

How it works

Each mode applies a deterministic transform (Unicode case mapping or word-split rules for programming cases).

Why use the Case Converter

Keep naming conventions consistent across code and content.

Common use cases

  • Code identifiers and file names
  • Headline styling
  • Bulk title cleanup

Case Converter FAQ

Does Title Case capitalize every word?

It capitalizes the first letter of each word after lowercasing the rest.

Is Unicode supported?

Browser string methods handle typical Unicode letters.

Yes.
