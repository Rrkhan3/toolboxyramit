Image Compressor

Reduce image file size with a quality slider and JPG or WebP output. Useful before upload to CMS or email. Compression is performed in the browser via canvas export.

Designed to process supported images locally in your browser.

How to use the Image Compressor

  1. Choose an image.
  2. Set quality and output format.
  3. Compress and compare sizes.
  4. Download when satisfied.

How it works

The image is redrawn to canvas and encoded at the selected quality, which typically shrinks photographic JPGs.

Why use the Image Compressor

Faster pages and smaller uploads without a desktop suite.

Common use cases

  • Web performance prep
  • Email attachments
  • Portfolio uploads

Image Compressor FAQ

Will quality loss be visible?

Lower quality settings increase compression artifacts; preview before using.

PNG input?

Photographic compression targets JPG/WebP; PNG may not shrink the same way.

Is processing local?

Designed to process supported images locally in your browser.
