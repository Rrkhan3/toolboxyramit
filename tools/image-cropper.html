Image Cropper

Specify left, top, width and height to crop precisely. Designers extract regions for assets. Canvas crop runs locally.

Designed to process supported images locally in your browser.

How to use the Image Cropper

  1. Upload an image.
  2. Enter crop x, y, width and height.
  3. Choose output format.
  4. Crop and download.

How it works

The selected rectangle is drawn to a new canvas and exported.

Why use the Image Cropper

Exact crops when GUI croppers are overkill.

Common use cases

  • Icon and thumbnail extraction
  • Removing borders
  • Asset prep

Image Cropper FAQ

What if the crop exceeds the image?

The tool reports an error if the region is outside the image bounds.

Is processing local?

Designed to process supported images locally in your browser.
