Image Resizer

Upload an image and set new width and/or height. Optionally lock aspect ratio and choose PNG, JPG or WebP output. Designed to process the file locally in your browser rather than uploading to ToolBoxy for resizing.

Designed to process supported images locally in your browser.

How to use the Image Resizer

  1. Choose an image file.
  2. Enter width and/or height.
  3. Select format and aspect options.
  4. Process and download the result.

How it works

The image is drawn to a canvas at the target size and exported as a blob in the chosen format.

Why use the Image Resizer

Prep images for web, social or print dimensions without desktop software.

Common use cases

  • Blog and social image sizes
  • Thumbnail generation
  • Reducing pixel dimensions before compress

Image Resizer FAQ

Is the image uploaded to a server?

The tool is designed to process supported images locally in your browser.

Max dimensions?

Very large sizes may be limited by browser memory.
