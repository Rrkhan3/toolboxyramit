Image Resolution Changer

Set new width and/or height, lock aspect ratio, or pick a preset. DPI metadata is not the same as pixel dimensions—increasing DPI does not create detail.

Designed to process supported files locally in your browser.

How to use Image Resolution Changer

  1. Upload an image.
  2. Enter dimensions or choose a preset.
  3. Download the resized image.

How it works

Canvas resamples the image to the requested pixel size.

Privacy

Your files are processed in your browser and are not uploaded to ToolBoxy servers.

Image Resolution Changer FAQ

Does increasing DPI improve quality?

No. DPI is metadata; only more pixels (or better source) can add detail.

Are files uploaded?

No.

Can I keep aspect ratio?

Yes—enable the checkbox.
