JavaScript Minifier

Paste JS, minify safely with Terser, and download. Syntax errors are reported clearly.

Designed to process supported files locally in your browser.

How to use JavaScript Minifier

  1. Paste JavaScript.
  2. Minify.
  3. Copy or download.

How it works

Terser runs entirely client-side. User code is never eval’d.

Privacy

Your files are processed in your browser and are not uploaded to ToolBoxy servers.

JavaScript Minifier FAQ

Is my code executed?

No. Only parsed and minified.

Is code uploaded?

No.

What if there is a syntax error?

Terser reports the error location.
