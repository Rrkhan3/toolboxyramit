Password Generator

Build passwords with uppercase, lowercase, numbers and symbols. Optional exclusion of ambiguous characters. Randomness comes from the browser crypto API when available; generation is local.

Designed to generate passwords locally in your browser.

How to use the Password Generator

  1. Set length and character options.
  2. Press Generate.
  3. Copy the password into your password manager.

How it works

Characters are sampled from the selected pools using cryptographic random values when available.

Why use the Password Generator

Stronger passwords than predictable patterns, without sending choices to a server.

Common use cases

  • New account setup
  • Rotating credentials
  • Teaching password strength

Password Generator FAQ

Should I store the password here?

Copy it to a trusted password manager; do not leave secrets in browser tabs.

Is generation local?

Yes. Designed to generate passwords in your browser.

Is it free?

Yes.
