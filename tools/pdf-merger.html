PDF Merger

Select several PDFs and merge them into a single document in order. Useful for packets and reports. Designed to process files locally in the browser with client-side PDF libraries.

Designed to process supported PDFs locally in your browser.

How to use the PDF Merger

  1. Add multiple PDF files.
  2. Order them as needed if the UI allows.
  3. Merge.
  4. Download the combined PDF.

How it works

Pages from each PDF are appended into a new document using in-browser PDF tooling.

Why use the PDF Merger

One file to share instead of many attachments.

Common use cases

  • Application packets
  • Report compilation
  • Print shop prep
