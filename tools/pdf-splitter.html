PDF Splitter

Pick a PDF and a page range to extract into a smaller file. Share chapters or forms without the full document. Client-side processing by design.

Designed to process supported PDFs locally in your browser.

How to use the PDF Splitter

  1. Choose a PDF.
  2. Enter the page range.
  3. Split/extract.
  4. Download the result.

How it works

Selected pages are copied into a new PDF document in the browser.

Why use the PDF Splitter

Send only what recipients need.

Common use cases

  • Extracting forms
  • Sharing a chapter
  • Reducing attachment size
