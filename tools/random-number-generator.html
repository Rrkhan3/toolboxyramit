Random Number Generator

Draw one or many random integers between minimum and maximum. Optionally require unique values. Useful for games, sampling and teaching. Local crypto randomness when available.

Everything runs in your browser. Your input is not sent to a server by this tool.

How to use the Random Number Generator

  1. Set min, max and count.
  2. Toggle allow duplicates.
  3. Press Generate.
  4. Copy or download the numbers.

How it works

Uniform integers are sampled with cryptographic random values when available; unique mode shuffles a pool.

Why use the Random Number Generator

Fair draws without spreadsheet RAND functions.

Common use cases

  • Classroom random selection
  • Game mechanics
  • Simple sampling

Random Number Generator FAQ

Are numbers truly random?

They use the browser’s cryptographic RNG when available, which is suitable for most non-cryptographic apps.

Is it free?

Yes.
